## Final project website for the "Social Graphs & Interactions" course, Technical University of Denmark (DTU), A.Y. 2016/17

The *Social Graphs & Interactions* was a course offered by the Technical University of Denmark (DTU). As part of the final hand in, students were asked to build a website to showcase, in a user friendly way, technical concepts about networks and natural language processing. Each group had chosen a specific topic and dataset to work on, and my project focused on the universe of characters and places from *The Lord of the Rings*.
